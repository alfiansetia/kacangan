VPN REMOTE

VPN Untuk Mengakses Router MikroTik Atau Perangkat Di Belakangnya

VPN REMOTE merupakan layanan VPN khusus untuk remote MikroTik dari luar jaringan walaupun tidak mempunyai IP Public. Cocok bagi yang sering di luar jaringan namun ingin tetap memantau jaringan. Selain MikroTik, VPN REMOTE juga untuk memantau perangkat di bawahnya seperti router, access point, web server.

Pilih Paket ↓ Hubungi WA

Fungsi VPN Remote

REMOTE MIKROTIK

Utamanya untuk remote Mikrotik dari luar jaringan via WinBox, Webfig, MikroTik App.

TUNNEL API MIKROTIK

Sebagai tunnel aplikasi API seperti Mikhmon, Mikbotam, dll.

REMOTE PERANGKAT LAIN

Remote perangkat di belakang MikroTik: access point, router, web server via port forward.

MENGGANTI NAMA ISP

Menyembunyikan nama ISP & IP publik pada speedtest.

Mengapa VPN Remote Kami?

LEBIH AMAN

Protokol terenkripsi, koneksi remote lebih aman.

INSTALASI CEPAT

Cukup jalankan script, selesai <1 menit.

LEBIH HEMAT

Jauh lebih hemat dibanding sewa IP Publik.

SERVER INDONESIA

Server di Indonesia, koneksi lebih cepat.

INGIN LAYANAN VPN REMOTE GRATIS?

Gratis jika berlangganan Cloud Userman atau beli Jasa Setting MikroTik.

FAQ

Bagaimana cara mengakses router di luar jaringan dengan layanan VPN Remote?

Gunakan WinBox, MikroTik App, atau browser (Webfig) melalui tunnel yang diberikan.

Apakah bisa untuk remote perangkat lain di belakang MikroTik?

Ya, gunakan fitur port forward (3 port) untuk access point, router, web server.

Apakah VPN Remote aman?

Ya, menggunakan protokol terenkripsi.
